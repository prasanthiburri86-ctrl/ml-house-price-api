# 🏠 House Price Prediction ML API (MLOps Project)

End-to-end machine learning deployment project built using FastAPI and Docker.

## 🚀 Features
- Linear Regression ML model for house price prediction
- FastAPI REST API for predictions
- Docker containerization
- Live cloud deployment on Render
- GitHub version control

## 🔧 Tech Stack
Python, Scikit-learn, FastAPI, Docker, GitHub, Render
