# 🏠 House Price Prediction ML API (End-to-End MLOps Project)

This project demonstrates a complete end-to-end production-ready MLOps pipeline for deploying a machine learning model using modern cloud and DevOps practices.

The system predicts house prices based on input size and is deployed as a scalable REST API using FastAPI, Docker, AWS, Kubernetes, and CI/CD automation.

---

## 🚀 Features

- Linear Regression ML model for house price prediction  
- FastAPI REST API for real-time predictions  
- Docker containerization for consistent deployment  
- AWS EC2 cloud deployment for production hosting  
- Kubernetes deployment for scalability and orchestration  
- GitHub Actions CI/CD pipeline for automated deployment  
- Public API access via cloud server  
- Production-ready project structure  

---

## ☁️ Cloud & DevOps Implementation

### AWS Cloud
- Deployed ML API on AWS EC2 instance  
- Configured security groups and public access  
- Docker-based deployment in cloud environment  
- Remote server management using SSH  

### CI/CD Automation
- Implemented GitHub Actions pipeline  
- Automated Docker build and deployment  
- Continuous Integration and Continuous Deployment setup
